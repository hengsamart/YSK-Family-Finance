## 🌟 លក្ខណៈពិសេសសំខាន់ៗ (Key Features)

### 1. 🌐 ទ្វេភាសាពេញលេញ (Full Bilingual: ភាសាខ្មែរ & English)
- ប្ដូរភាសាភ្លាមៗដោយចុចប៊ូតុងមួយ (One-click Instant Language Toggle 🇰🇭 / 🇬🇧)។
- ប្រើប្រាស់ពុម្ពអក្សរខ្មែរ **Kantumruy Pro** ស្អាត ច្បាស់ ស្រួលមើលលើគ្រប់ឧបករណ៍ (ទូរស័ព្ទ និងកុំព្យូទ័រ)។

### 2. 💵 គាំទ្ររូបិយប័ណ្ណពីរ (Dual Currency: USD $ & KHR ៛)
- កត់ត្រាចំណូល-ចំណាយជាប្រាក់ **ដុល្លារ ($)** ឬ **រៀល (៛)** តាមទម្លាប់ជាក់ស្ដែងនៅកម្ពុជា។
- ប្ដូររូបិយប័ណ្ណបង្ហាញលើផ្ទាំង Dashboard ភ្លាមៗ (Instant Currency Switcher)។
- កំណត់អត្រាប្តូរប្រាក់ផ្ទាល់ខ្លួនបានយ៉ាងងាយស្រួល (ឧ. 1 USD = 4,100 KHR)។

### 3. 🧠 ការវិភាគឆ្លាតវៃ & ពិន្ទុសុខភាពហិរញ្ញវត្ថុ (Smart Analytics & Health Score)
- **Financial Health Score (0-100)**៖ គណនាកម្រិតសុខភាពហិរញ្ញវត្ថុគ្រួសារ (ល្អឥតខ្ចោះ, ល្អប្រសើរ, មធ្យម, គួរប្រុងប្រយ័ត្ន)។
- **Smart Insights Engine**៖ ផ្ដល់នូវអនុសាសន៍ និងការវិភាគដោយស្វ័យប្រវត្តិ (ឧ. អត្រាសន្សំលើសគោលដៅ, ចំណាយលើម្ហូបអាហារច្រើនជាងគេ, គោលការណ៍ 50/30/20)។
- **ក្រាហ្វិកវិភាគទិន្នន័យ (Interactive Charts)**៖ ក្រាហ្វិកប្រៀបធៀបចំណូល-ចំណាយ ៦ ខែ និងការបែងចែកចំណាយតាមជំពូក។

### 4. 👨‍👩‍👧‍👦 បែងចែកតាមសមាជិកគ្រួសារ (Family Member Tracking)
- បែងចែកប្រតិបត្តិការតាមសមាជិក៖ **ឪពុក (Dad)**, **ម្ដាយ (Mom)**, **កូនប្រុស (Son)**, **កូនស្រី (Daughter)** ឬ **ចំណាយរួមគ្រួសារ (Shared)**។
- គាំទ្រមធ្យោបាយទូទាត់ទូទៅនៅកម្ពុជា៖ **ABA Bank**, **ACLEDA**, **Wing/TrueMoney**, **សាច់ប្រាក់សុទ្ធ (Cash)**, **កាតឥណទាន**។

### 5. 🎯 កញ្ចប់ថវិកា, បំណុល & គោលដៅសន្សំ (Budgets, Debts & Goals)
- **កញ្ចប់ថវិកាប្រចាំខែ (Monthly Budgets)**៖ កំណត់ទំហំចំណាយអតិបរមាក្នុងមួយជំពូក ជាមួយរបារ Progress Bar បង្ហាញពណ៌ព្រមាន (បៃតង = ល្អ, លឿង = ជិតដល់, ក្រហម = លើសកម្រិត)។
- **បំណុល & កម្ចី (Debts & Loans)**៖ តាមដានប្រាក់ដែលយើងជំពាក់គេ (ត្រូវសង) និងប្រាក់ដែលគេជំពាក់យើង (ត្រូវទារ) ព្រមទាំងថ្ងៃកំណត់សង។
- **គោលដៅសន្សំ (Savings Goals)**៖ កំណត់គោលដៅទិញផ្ទះ/ឡាន, ដំណើរកម្សាន្ត ឬកញ្ចប់គ្រាអាសន្ន។

### 6. 📊 ទាញយករបាយការណ៍ & បម្រុងទុកទិន្នន័យ (Export & Backup)
- ទាញយករបាយការណ៍ជា **Excel / CSV** (គាំទ្រពុម្ពអក្សរខ្មែរ UTF-8 BOM)។
- បោះពុម្ពរបាយការណ៍ហិរញ្ញវត្ថុ (Print-ready Report)។
- Backup & Restore ទិន្នន័យទាំងអស់ជា JSON គ្រប់ពេលវេលា។

## 📱 របៀបប្រើប្រាស់លើទូរស័ព្ទដៃ (Mobile App / PWA)

កម្មវិធីនេះជា **Progressive Web App (PWA)** ដែលអាចដំឡើងលើទូរស័ព្ទដូច App ពិតៗ ដោយមិនចាំបាច់ចូល App Store/Play Store៖

1. បើក Link កម្មវិធី (GitHub Pages ឬ Local IP លើ Wi-Fi តែមួយ) នៅលើ **Chrome (Android)** ឬ **Safari (iOS/iPhone)**។
2. ចុចលើ Menu (សញ្ញាចុច ៣ នៅ Chrome ឬ Share Icon នៅ Safari)។
3. ជ្រើសរើស **"Add to Home Screen"** ឬ **"ដំឡើងកម្មវិធី / Install App"**។
4. App Icon របស់ **YSK Finance** នឹងបង្ហាញលើអេក្រង់ទូរស័ព្ទរបស់អ្នកភ្លាមៗ ហើយអាចបើកប្រើប្រាស់បានទោះបីជាគ្មានអ៊ីនធឺណិត (Offline Mode)។

## 💻 របៀបដំណើរការលើកុំព្យូទ័រ (Computer / Desktop)

### វិធីទី ១៖ បើកជា Native Desktop App (មានផ្ទាំងផ្ទាល់ខ្លួន)
- Double-click លើ file **`start_desktop.bat`**
- កម្មវិធីនឹងបើកឡើងជាកម្មវិធី Desktop ស្អាតទាន់សម័យ (PyWebview)។

## 🚀 ប្រព័ន្ធ GitHub Auto-Update (របៀបដំឡើង និងធ្វើបច្ចុប្បន្នភាព)

ប្រព័ន្ធត្រូវបានរៀបចំជាមួយ **GitHub Actions CI/CD** រួចជាស្រេច (`.github/workflows/deploy.yml`)។

### ជំហានទី ១៖ បង្កើត GitHub Repository
1. ចូលទៅកាន់គណនី GitHub របស់អ្នក ហើយបង្កើត Repository ថ្មីមួយ (ឧ. ឈ្មោះ `YSK-Family-Finance`)។
2. ភ្ជាប់ថតឯកសារនេះទៅកាន់ GitHub ដោយរត់ពាក្យបញ្ជាក្នុង PowerShell / Command Prompt៖
   ```bash
   git remote add origin https://github.com/<ឈ្មោះ_GitHub_របស់អ្នក>/YSK-Family-Finance.git
   git add .
   git commit -m "Initial release v1.0.0"
   git push -u origin main
   ```

### ជំហានទី ២៖ បើកដំណើរការ GitHub Pages
1. ចូលទៅ Settings ក្នុង GitHub Repo របស់អ្នក -> **Pages**
2. នៅត្រង់ **Build and deployment -> Source** ជ្រើសរើសយក **GitHub Actions**
3. រាល់ពេលអ្នក Push កូដថ្មី GitHub Actions នឹង Deploy ដោយស្វ័យប្រវត្តទៅកាន់ Link Free របស់អ្នក (ឧ. `https://<user>.github.io/YSK-Family-Finance/`)។

### ជំហានទី ៣៖ ការធ្វើបច្ចុប្បន្នភាពដោយស្វ័យប្រវត្តិ (Auto-Update)
- **នៅលើទូរស័ព្ទ & Web Browser**៖ នៅពេលមានការផ្លាស់ប្តូរនៅលើ GitHub ប្រព័ន្ធនឹងបង្ហាញ Notification Banner ៖
  > *"🎉 មានកំណែប្រែថ្មី (New Version Available)! ចុចដើម្បីធ្វើបច្ចុប្បន្នភាពភ្លាមៗ"*  
  ចុចប៊ូតុងមួយ App នឹងទាញយកកូដថ្មី ហើយ Refresh ដោយស្វ័យប្រវត្តិ។
- **នៅលើកុំព្យូទ័រ**៖ គ្រាន់តែ double-click លើ file **`update.bat`** នោះកុំព្យូទ័រនឹងទាញយកកំណែចុងក្រោយពី GitHub ភ្លាមៗ!
